# Challenges

Desafios práticos do estilo entrevista técnica — diferentes dos exercícios conceituais dos blocos.

## Como funciona

Cada challenge tem dois arquivos:
- `README.md` — descrição do desafio, requisitos, exemplos e bônus opcionais
- `Challenge.java` — arquivo com boilerplate mínimo para você preencher

## Diferença para os exercícios dos blocos

| Exercícios (blocks 1-4) | Challenges |
|---|---|
| Foca em um conceito Java isolado | Problema prático completo |
| Tem scaffold com `TODO`s guiados | Você decide a estrutura |
| Avalia correção conceitual | Avalia lógica e design |

## Como gerar um novo desafio

```
/new-challenge normal-challenge
```

Gera um desafio prático novo — tipo "crie um jokenpô", "implemente uma fila de atendimento" — e cria os arquivos automaticamente na pasta `challenges/`.

## Como fazer review de um challenge

```
/review-submission challenges/<nome-do-challenge>
```
